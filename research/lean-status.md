# Lean verification status

**Partial formalization.** Lean proves weak unimodality for both central staircase families for every row count through 191. The full conjecture is stated as `CentralUnimodality.Conjecture34`. Its universal proof is still in progress. The [computer-assisted research proof](../proof.md) gives the intended argument for the remaining sizes.

The kernel-checked 63-row base theorem uses only arithmetic on natural numbers. In the formal proof every positive row with ballot length at most 127 is evaluated at base $2^{128}$. Reading its digits from low to high tests every adjacent pair through the degree of the shape. The 95-row theorem uses base $2^{192}$ to check the additional sizes and the reflected comparisons. Both verifiers compute their coefficients and detect the peak inside Lean.

Lean constructs the raising and lowering operators on the rational polynomial ring in paired variables and on the quotient by the ideal of positive-degree simultaneous invariants. In the image of the alternating polynomials of total degree $d$, raising injects degree $i$ into degree $j$ whenever $i\le j$ and $i+j\le d$. The kernel also proves that these spaces vanish below the induction cutoff. The sole additional ordinary Dyck input on this route is the univariate Hilbert-series specialization for the explicit quotient spaces. ## Reproduction

Use the pinned Lean 4.36.0 toolchain and mathlib revision in the Lake manifest. From the repository root run

~~~sh
lake build
lake env lean research/CheckLean.lean
LEAN_NUM_THREADS=1 lake env leanchecker --verbose --fresh CentralUnimodality
~~~

An independent exact coefficient calculation covers both families at every size through 191. For the first 12 sizes it also enumerates the strict partitions directly. Run `python3 -B verify.py --max-n 191 --direct-n 12 --upper-curvature`.

The 321-avoiding superpatterns repository also replays each project module separately. To reproduce that check, run

~~~sh
for file in CentralUnimodality/*.lean; do
  module=${file##*/}
  LEAN_NUM_THREADS=1 lake env leanchecker --verbose "CentralUnimodality.${module%.lean}" || exit 1
done
~~~

The audit checks the exact finite unimodality theorems, the strict-partition characterization, the signed rank identity, and the Fourier residual bound. It checks the transitive dependencies of every project declaration against the same axiom allowlist used in the 321-avoiding superpatterns repository, consisting of `propext`, `Classical.choice` and `Quot.sound`. The fresh replay checks the imported declarations and the project modules from an empty kernel environment.
